# AMBA-AXI-BUS-PROTOCOL
BUS COMMUNICATION PROTOCOL VERIFICATION - AMBA AXI BUS PROTOCOL

This project focuses on designing and verifying the AMBA AXI (Advanced eXtensible Interface) bus communication protocol using SystemVerilog. The AXI protocol is widely used in System-on-Chip (SoC) designs for high-speed data transfer between multiple masters and slaves. The project ensures correct data transfer, address decoding, burst transactions, and handling of multiple outstanding and out-of-order transactions.
